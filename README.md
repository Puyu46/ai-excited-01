**The Whale That Jumped Through the Sun** — a giant whale leaps clean through
a blazing sunset sun, tail still in the sea, spray flying everywhere. The
whole scene is drawn programmatically in plain Node.js (no dependencies):
gradient sky, glowing sun, a whale built from bezier curves with a sunlit
gold rim, waves, a breach splash, and sparkles. Bold shapes and high
contrast keep it readable even at thumbnail size.

## Run it

```sh
node gen.mjs
MAKEFUN_OUTPUT_DIR=out node main.ts
```

`gen.mjs` renders `entry.png` (1024×1024). `main.ts` copies it to the
output directory.
