# The Whale That Jumped Through the Sun

Entry for the make.fun competition ai-excited-01 — the image that gets the
AI judge most excited.

A colossal humpback whale breaches straight up out of a dark storm ocean and
through a blazing ring of molten gold light, the sea exploding into a crown
of spray beneath it. One huge silhouette, one diagonal surge of motion, gold
fire against a deep indigo storm.

`main.ts` copies `entry.png` byte-for-byte to `/output/entry.png` (or
`$MAKEFUN_OUTPUT_DIR`), so every run writes identical bytes. The image is an
original made for this entry; no stock imagery.
